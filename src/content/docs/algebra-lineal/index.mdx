Casi todo el machine learning es álgebra lineal disfrazada: los datos son vectores, los modelos son matrices, entrenar es proyectar y la estructura se encuentra con eigenvectores. Este curso construye esa base de nivel básico a medio, con visualizaciones que puedes manipular — y cada concepto conectado al modelo de ML donde lo volverás a ver.
